# Локальные шрифты

Приложение использует два семейства из Google Fonts, размещённые локально. CSS подключает только соответствующие Unicode-подмножества, когда на странице встречаются их символы; рантайм не обращается к Google Fonts CDN.

| Семейство | Файлы | Вес | Размер файлов |
|---|---|---:|---:|
| Golos Text | `GolosText-{latin,latin-ext,cyrillic,cyrillic-ext}.woff2` | 400–700 | 96 636 байт |
| Literata | `Literata-{latin,latin-ext,cyrillic,cyrillic-ext}.woff2` | 400–600 | 221 092 байта |

Файлы WOFF2 получены из Google Fonts CSS API 23 октября 2026 года для переменных начертаний Golos Text и Literata. Google Fonts CSS задаёт диапазоны Unicode и весовые оси для этих файлов. Исходные страницы семейств: [Golos Text](https://fonts.google.com/specimen/Golos+Text) и [Literata](https://fonts.google.com/specimen/Literata). Репозитории и метаданные Google Fonts: [golos-text](https://github.com/google/fonts/tree/main/ofl/golos-text) и [literata](https://github.com/googlefonts/literata).

Оба семейства распространяются по SIL Open Font License 1.1. Полные тексты лицензий и уведомления об авторских правах сохранены рядом с файлами: [OFL-GolosText.txt](OFL-GolosText.txt) и [OFL-Literata.txt](OFL-Literata.txt). Официальные исходники лицензий: [Golos Text OFL](https://github.com/googlefonts/golos-text/blob/main/OFL.txt), [Literata OFL](https://github.com/googlefonts/literata/blob/main/OFL.txt).
