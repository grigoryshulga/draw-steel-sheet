# Иллюстрации «Стального листа»

Каталог соответствует данным проекта: 10 классов, 14 происхождений, 22 комплекта, 18 карьер. Проверенные интернет-источники и их ограничения записаны в [исследовании официальных артов](../art-research-official.md) и [исследовании комплектов и карьер](../art-research-kits-careers.md).

Официальная основа для девяти классов — [пресс-материалы MCDM](https://www.mcdmproductions.com/press). Для двенадцати базовых происхождений использованы подписанные портреты и иллюстрация Time Raiders из общедоступных превью [Draw Steel Heroes в магазине MCDM](https://shop.mcdmproductions.com/products/draw-steel-heroes-pdf). Неизменённые скачанные оригиналы лежат в `assets/art-originals/`.

Для карточек эти изображения адаптированы встроенным ImageGen: удалены страница, сцена, рамки и подписи, сохранён прозрачный фон. Это AI-обработка официальной основы, а не заявление о побитовом совпадении с оригиналом. Данные `origin: official` обозначают происхождение иллюстрации; подпись в интерфейсе сообщает об обработке. Новые рисунки Призывателя, Тауруса, Ящера, комплектов и карьер имеют `origin: generated` и не выдаются за официальные MCDM-иллюстрации.

Luna-агенты использовали встроенный `image_gen`; внешние платные API и CLI-генерация не подключались. Полные наборы промптов или честно обозначенные описания операций сохранены в `*-manifest.json` этого каталога, общая спецификация — [DIRECTION.md](DIRECTION.md). `ancestries-jobs.json` содержит полные подготовленные промпты происхождений.

Финальные прозрачные PNG: `public/art/classes/`, `public/art/ancestries/`, `public/art/kits/`, `public/art/careers/`. Уменьшенные PNG для карточек: `public/art/previews/`. Полные изображения используются в крупном просмотре. Их связь с названиями, статьями, размерами, источниками и кредитами хранится в `src/data/art.generated.json`. Приложение загружает их локально, без hotlink на MCDM.

Пересборка после добавления или исправления изображений:

```sh
npm run data:art-previews
node scripts/build-art-manifest.mjs --check
npm test
npm run build
```

Для пересоздания превью нужен ImageMagick (`magick`). Он только уменьшает копии для доставки; художественные изменения и удаление фона выполнялись ImageGen. Приложению и обычной сборке ImageMagick не требуется.

Источники и кредиты доступны пользователю в «Ещё → О листе → Иллюстрации» и под изображениями статей Кодекса.
