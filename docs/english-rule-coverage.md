# Покрытие английских оригиналов

Повторить: `npm run content:build` и `node scripts/originals/coverage.mjs`. Аудит считает каждый доставляемый пакетом объект один раз. Наличие текста не гарантирует, что он соответствует полному русскому правилу. В ленивой доставке `originalCoverage.status` означает `complete` для проверенного источника и границ, `excerpt` для не подтверждённой полноты, `missing` для отсутствия текста; `reason` различает домашний (`homebrew`), редакционный (`editorial`), недоступный источник и непроверенную границу. Это консервативная оценка: `excerpt` не означает, что текст обязательно неполный.

Для 40 прозаических статей сопоставлены 309 последовательных подразделов (`scripts/originals/maps/prose-sections.json`); ещё для 24 статей проверены 239 ограниченных подразделов (`bounded-prose.json`). Сборка проверяет ID, названия, источники и границы. `0101` включает пять подразделов от Tactical до If You're Coming From D20 Fantasy и заканчивается перед Glossary Index. Для `1408` дополнительно включён соответствующий английский раздел Keep Going or Stop; отдельные редакции всё же могут различаться. Для восьми составных сущностей полные исходные разделы проверены отдельно (`entity-sections.json`), включая Stormwight, три проекта Imbue Treasure, Shadowmeld, Psionic Gift, Wode Road и Unstoppable Mind.

Из 2 432 сущностей 2 415 имеют статус `complete`, а 17 домашних сущностей не имеют оригинала; записей со статусом `excerpt` среди сущностей нет. Сверены 103 отдельные особенности: для 54 листовых разделов восстановлен полный текст, для 49 вводных частей исключены вложенные сущности и сохранены соответствующие таблицы. Карты `entity-leaves.json` и `entity-intros.json` закрепляют раздел, границы и хеш русского текста; сборка откажется принимать изменившееся сопоставление. Для 12 происхождений оставлены введение и начало раздела черт, а отдельные черты не дублируются. Десять агрегатов классов содержат введение, основы и полный первый уровень закреплённого источника, включая карточки способностей; уровни выше первого остаются отдельными статьями. Для Summoner используются закреплённые введение и первый уровень, хотя русские заглушки не содержат правил. Сущность проекта Imbue Treasure ограничена вступлением, а улучшения вынесены в другие статьи.

Из 959 статей 952 имеют статус `complete`, одна — `excerpt`, шесть не имеют оригинала. Источники 662 статей Monsters идентичны закреплённому снимку; 90 классовых статей Heroes и ещё 27 статей происхождений и тематических разделов собраны в отдельный `englishEdition` с `kind: "source"` по порядку исходных разделов. Сущность используется ссылкой только при совпадении её текста с разделом; иначе выводится оригинальный Markdown. В entity-only списках исключаются вложенные способности, уже входящие в полную родительскую запись. `1616` содержит исходное вступление проекта; типы улучшений доставляются отдельными статьями.

Единственная статья со статусом `excerpt` — `1102`, таблица нюансов. Оригинальная таблица SCC включена в английский текст, но её числовой порядок отличается от русской редакции: например, значение 1 в русском тексте — «Аварийная посадка», а в английском — Advanced Studies. Автоматически считать результаты одного броска эквивалентными нельзя.

Для шести домашних и редакционных статей и 17 домашних сущностей дополнительно доставляется авторский `englishEdition` из `content/english-editions.json`. Это перевод, который не изменяет `originalDescription` и не выдаётся за оригинал.

Все 273 термина теперь имеют английский источник; 46 прежних пропусков получены из канонических правил Monsters или из соответствующих разделов Heroes и Summoner. Для Recovery, Experience, Summoner и обозначений кубов это тематические разделы, а не дословные эквиваленты кратких русских определений. Восстановлены десять английских уровней Summoner; русские страницы уровней остаются пустыми. Английский обзор `0401` следует соответствующим разделам книги; состав происхождений и формулировки могут отличаться между редакциями.

Новые внешние снимки получены из независимого SteelCompendium/data-unified, commit `bdb12093b1d07bf8674453796eac907a09dd7dd3`, а не из Forge Steel. Их можно воспроизвести командой `node scripts/originals/import-scc-audit.mjs <checkout> --check`; локальный checkout Forge Steel использовался только для сверки. Данные компендиума могут содержать ошибки; см. [источник](https://steelcompendium.io/v2/).
