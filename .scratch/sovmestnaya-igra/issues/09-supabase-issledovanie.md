# Как Supabase поддерживает защищённую синхронизацию стола?

Label: wayfinder:research
Type: research
Status: resolved
Assignee: research/supabase-realtime

## Question

По актуальной официальной документации исследовать Auth, RLS и Realtime для данных с индивидуальным доступом, переподключение и ограничения масштабирования. Указать вопросы, требующие собственных измерений и проверки политики доступа.

## Answer

RLS ограничивает доступ к строкам; для выборочной видимости JSON нужна проверяемая серверная проекция или другая модель данных. События Realtime не заменяют сохранённое состояние и проверку восстановления после отключения. Доставку предметов нужно согласовать с конкурентными сохранениями. Варианты, первичные источники и необходимые эксперименты: [Supabase Realtime](../../../docs/research/supabase-realtime.md).
