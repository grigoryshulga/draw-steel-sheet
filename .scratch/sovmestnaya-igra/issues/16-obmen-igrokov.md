# Как игроки обмениваются предметами между собой?

Label: wayfinder:grilling
Type: grilling
Status: open
Blocked by: 05

## Question

Какой игровой сценарий передачи и обмена предметов поддерживается? Зафиксировать уже подтверждённый сценарий ниже и обсудить только неясности, которые существенно меняют опыт игроков. Сохранность предметов при отменах, повторах и потере сети обеспечить при инженерном проектировании, не заставляя пользователя разбирать редкие технические случаи.

## Comments

При обсуждении предметов пользователь выбрал передачу в дар и взаимный обмен; участия ведущего не требуется, достаточно согласия участвующих игроков. Остальные условия обмена ещё не обсуждены.

Пользователь подтвердил основной сценарий: два игрока одного стола выбирают предметы и количество, видят условия и оба подтверждают обмен; предметы переходят одновременно. Возможен и односторонний подарок без ответного предмета.
