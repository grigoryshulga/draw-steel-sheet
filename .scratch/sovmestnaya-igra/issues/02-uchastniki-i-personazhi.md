# Как устроены участие в столах и принадлежность персонажей?

Label: wayfinder:grilling
Type: grilling
Status: resolved
Assignee: Codex

## Question

Может ли человек быть ведущим и игроком, состоять в нескольких столах и иметь несколько персонажей в одном столе? Что происходит при выходе, исключении, удалении стола или аккаунта и как передаётся роль ведущего?

## Comments

Первый раунд: один герой может состоять только в одном столе; один игрок может добавить в стол нескольких героев, но только один активен; ведущий не может добавить своего героя за стол, который ведёт.

Второй раунд: игрок самостоятельно меняет активного героя; ведущий видит только активного героя. Для участия того же героя в другом столе создаётся независимая копия, оригинал остаётся в прежнем столе.

Третий раунд: человек может участвовать в любом количестве столов и иметь разные роли в разных столах. Если игрок выходит из стола или его исключают, герои остаются у игрока, ожидающие предложения предметов отменяются. Ведущий может передать стол другому участнику или закрыть стол.

Четвёртый раунд: новый ведущий должен принять передачу роли; при передаче его герои убираются из стола, но остаются у владельца. Закрытие переводит стол в архив с возможностью восстановления.

Пятый раунд: прежний ведущий после передачи роли остаётся участником и может добавить героя как игрок. Герой остаётся связан с архивированным столом, для другого стола нужна независимая копия. Восстановить архив может последний ведущий.

Шестой раунд: архивный стол доступен участникам для просмотра, но совместные действия остановлены. Прежде чем удалить аккаунт, ведущий передаёт свои столы или окончательно удаляет их. Отдельного героя игрока может убрать из стола только ведущий.

Седьмой раунд: при удалении героя из стола его неподтверждённые предложения отменяются, герой и полученные предметы остаются у игрока. Исключённый игрок возвращается только с разрешения ведущего. При удалении аккаунта игрока удаляются его герои и доступ, сохраняется обезличенная история стола.

Восьмой раунд: после удаления активного героя игрок сам выбирает следующего; до выбора активного героя нет. Предложения предметов при архивировании приостанавливаются и снова доступны при восстановлении. При удалении аккаунта игрока в истории сохраняются события с именами его героев, но без имени игрока. Сохранённое имя героя может позволить установить личность, поэтому это не гарантия полной анонимности.

Девятый раунд: игрок может выйти из архивированного стола; герои остаются в его аккаунте. Архив показывает лист в состоянии на момент архивирования, даже если игрок позже меняет героя.

## Answer

- Человек может участвовать в неограниченном числе столов и быть ведущим одного и игроком другого. Ведущий не добавляет и не играет своим героем за столом, который ведёт.
- Герой состоит не более чем в одном столе. Чтобы использовать его в другом, пока оригинал остаётся в прежнем, создаётся независимая копия. Игрок может добавить нескольких героев за стол, но активен не более одного; выбор и смена активного героя принадлежат игроку. Ведущий видит только активного героя, не запасных.
- Отдельного героя игрока из стола может убрать только ведущий. Герой и полученные предметы остаются у владельца, неподтверждённые предложения отменяются. Если удалён активный герой, следующего выбирает игрок; до этого активного героя нет.
- Игрок может выйти из обычного или архивированного стола; ведущий может его исключить. Герои остаются у игрока, неподтверждённые предложения отменяются. Исключённый игрок может вернуться только с разрешения ведущего.
- Ведущий может предложить передачу роли участнику; тот должен её принять. Герои нового ведущего при передаче удаляются из стола, но остаются у владельца. Прежний ведущий остаётся участником и может добавить героя как игрок.
- Ведущий может архивировать стол; восстановить его может последний ведущий. Архив доступен для просмотра, совместные действия приостановлены, лист показывает состояние на момент архивирования. Предложения предметов приостановлены до восстановления, если они не отменены из-за выхода игрока или удаления героя. Герой остаётся связан с архивным столом; для другого нужна независимая копия.
- Прежде чем удалить аккаунт, ведущий передаёт свои столы или окончательно удаляет их. При удалении аккаунта игрока удаляются его герои и доступ; в истории стола остаются события с именами героев без имени игрока. Сохранение имён героев не гарантирует анонимности.

Границы архивных снимков при отзыве доступа и удалении аккаунта обсуждаются отдельно вместе с правилами приватности.
