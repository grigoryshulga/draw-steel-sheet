# Как архивные снимки учитывают отзыв доступа и удаление аккаунта?

Label: wayfinder:grilling
Type: grilling
Status: resolved
Assignee: Codex
Blocked by: 03

## Question

Какую версию разрешённых разделов хранит и показывает архивный стол? Что происходит со снимками и именами героев, если игрок отзывает доступ, выходит из архивного стола либо удаляет аккаунт? Как совместить просмотр состояния на момент архивирования с выбранными правилами приватности и сохранения истории?

## Comments

Первый раунд: после архивирования игрок может изменить настройки доступа; закрытый необязательный раздел исчезает и из архивного снимка. При выходе игрока из архивного стола снимки его героев больше не доступны остальным, но события и имена героев остаются в истории. При удалении аккаунта содержимое снимков удаляется, в истории остаются события и имена героев.

Второй раунд: при архивировании сохраняется снимок всех разделов, включая закрытые; показывать их можно только с разрешения владельца. Если игрок закрыл ранее открытый архивный раздел, а затем снова открыл, показывается сохранённое состояние на момент архивирования. После удаления аккаунта данные могут оставаться в резервных копиях до окончания срока хранения; при восстановлении копии удаление применяется повторно.

Третий раунд: при выходе игрока из архивного стола снимки его героев удаляются, в истории остаются события и имена героев. После восстановления стола в продолжающейся игре используется текущее состояние героя; архивный снимок сохраняется в истории.

## Answer

- Снимок архивированного героя содержит состояние всех разделов на момент архивирования, в том числе закрытых. Доступ определяется актуальными настройками владельца: при закрытии раздел исчезает, при повторном открытии показывается сохранённое состояние. Игрок может менять доступ после архивирования.
- При выходе игрока из архивного стола снимки его героев удаляются, а в истории остаются события и имена героев. При удалении аккаунта содержимое снимков тоже удаляется; события и имена героев остаются без имени игрока.
- Данные удалённых аккаунтов могут оставаться в резервных копиях до окончания срока хранения. При восстановлении из копии удаление должно применяться повторно.
- При восстановлении стола игра продолжается с текущим состоянием героя; архивный снимок сохраняется в истории, если он не был удалён при выходе или удалении аккаунта.
