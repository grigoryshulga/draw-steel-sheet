# Примечания к источнику Monsters

Относится к ревизии `bdb12093b1d07bf8674453796eac907a09dd7dd3` data-unified. Английские оригиналы сохранены в канонических записях; эти заметки не являются исправлениями официальных правил.

| Место | Наблюдение и решение |
| --- | --- |
| `chapter/retainers.json` | Упоминается таблица развития, отсутствующая в выгрузке главы. Отдельная редакционная таблица составлена по явным пунктам и примеру той же главы. На уровнях 4/7/10 можно выбрать способность помощника либо его роли; обе группы записей показаны рядом с блоком помощника. |
| `rule/monster/malice.json` | Правило прекращает получение Раздора от героя после смерти, пример говорит о выбывании из боя. Обе формулировки сохранены. |
| `chapter/monster-basics.json` | В подкреплениях задачи Hold Them Off указано EV героя, хотя при построении столкновения используется ES. Обозначение сохранено. Отдельная строка `Draw Steel` также присутствует в исходнике. |
| Тролли, включая Troll Mercenary и Limbjumble | У огненной уязвимости нет числа; встречаются `Acid 5, fire` и `Acid 8, fire`. Недостающее значение не добавлено. |
| Chimeron | EV 9 в блоке и EV 11 в таблице группы демонов. Сохранены оба значения. |
| Bugbear | Необычные значения Выносливости 109 у громилы и 80 у скрытника совпадают с исходником. |
| Hobgoblin / Slaughter Demon | В шапке таблицы есть лишняя шестая пустая ячейка при пяти столбцах разделителя и данных. В переводе пустая ячейка удалена, чтобы таблица разбиралась как статблок; все значения и оригинал сохранены. |
| Granite Stone Giant, Radenwight Malice | `a 14 wall` и `a 10 wall` проверены по определению Wall в Heroes: число обозначает количество клеток стены. Использованы «стена из 14 клеток» и «стена из 10 клеток» без ограничения её длины. |
| Demon / `A Hero Faces the Void`, аналогичные `within distance` | Число в самой фразе отсутствует. Сохранено «в пределах дистанции»; дистанция способности остаётся в её блоке. |
| Olothec / `Return to Perfection` | Для второго и третьего тиров указан одинаковый порог `Р < 3`. Сохранён. |
| War Dog / `Loyalty Unto Death` | Результат 17+ содержит только отталкивание на 2. Дополнительный эффект не добавлен. |
| War Dog / Teletite–Teletalite | Названия в перечне группы и отдельной записи различаются. Варианты сохранены. |
| Time Raider Armiger, Voiceless Talker Artillerist | Оборванные `affecting the.` и `line of effect to the.` переданы с подразумеваемым по контексту существом; оригинальные обрывы доступны в английских полях. |
| Wode Elves | Отдельный фрагмент `one of the following features.` сохранён. Слитый с предыдущим примером заголовок `Reclaimer Force, 74 EV` отделён. |
| Опечатки и имена | Явные `oppotunity`, `lycanthpy`, `difficu terrain`, `etrenched`, `reducetd`, `affed` переданы по контексту. Латинские названия `Draco Vulgaris` и `Draco Nobilis` сохранены. Различающиеся написания Yllyric/Yllric не объявлены разными языками по одному лишь расхождению букв. |

После объединения партий выровнены повторяющиеся особенности, все ключевые слова существ, названия классов соперников, «Зелень» элементалиста и «Пространство времён». Недостающие ссылки восстановлены по оригиналам. Числовые последовательности и полный набор ссылок сверяются автоматически для каждой записи.
